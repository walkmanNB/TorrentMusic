# 🎵 Mini Decentralized Music Player

一个基于 PyQt5 构建的极简、现代、去中心化的毛玻璃风格音乐播放器。支持通过 GitHub 托管的 JSON 订阅源和云端音频资源，实现零服务器成本的个人音乐库自由掌控；同时内置了接入 `lrclib.net` 的去中心化多源歌词同步系统，拥有媲美 Apple Music 的沉浸式大屏歌词体验。

---

## ✨ 核心特性

- **去中心化架构**：数据与音频文件全部托管于 GitHub 仓库（或任意直链 JSON 源），无需依赖任何商业音乐服务器，完全由你自主掌控。
- **现代毛玻璃 UI**：全界面采用精美的 Acrylic / Glassmorphism 样式，支持自定义流光色斑背景与无边框窗口自由拖拽。
- **多源智能歌词同步 (`lrclib.net`)**：
  - **简繁双轨并发搜索**：自动通过 OpenCC 生成简体与繁体变体并发查询，按 ID 去重合并，绝不漏掉异体字歌词。
  - **智能模糊匹配**：结合 NFKC 归一化、序列相似度、Dice 关键词重合度及时长加成，自动挑选最精准的歌词。
- **沉浸式歌词大屏**：支持一键开启类 Apple Music 风格的独立大屏控制台，实现左侧超大专辑封面、右侧并排播放列表与实时高亮滚动歌词的完美联动。
- **订阅持久化管理**：内置优雅的订阅源管理器，支持多歌单源切换、即时落盘与下次启动自动恢复。
- **多档播放模式**：支持列表循环、单曲循环与顺序播放。
- **后台异步加载**：所有网络请求（歌单拉取、封面下载、去中心化歌词搜索）均通过多线程异步执行，保证 UI 界面永远丝滑不卡顿。

## 🚀 快速上手

### 1. 环境依赖

确保本地已安装 Python 3.8+，然后在项目根目录下执行以下命令安装依赖：

```bash
pip install PyQt5 requests opencc-python-reimplemented
```

*(注：`opencc-python-reimplemented` 为可选依赖，若未安装将自动优雅降级为仅原始关键词搜索)*

### 2. 运行项目

克隆仓库并运行主程序：

```bash
python run.py
```

## 📂 项目结构

```text
├── run.py            # 主程序入口（UI 界面、播放核心、订阅与歌词调度）
├── lrcrequest.py     # 去中心化歌词获取模块（简繁双轨并发 + 智能模糊匹配）
└── floatlyrics.py    # Apple Music 风格的沉浸式大屏毛玻璃歌词窗口
```
